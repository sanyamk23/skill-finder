How It Works

Four steps. Zero clutter.

The complete just-in-time workflow.

01

Search

Tell Claude what you need. It searches the skills.sh ecosystem for the best matches.

npx skills find <query>
02

Install

The best match is temporarily installed to your environment.

npx skills add <skill> -y
03

Use

Claude reads the skill's instructions and executes your task with expert guidance.

Read SKILL.md → Execute task
04

Remove

Once done, the skill is automatically removed. Your environment stays clean.

npx skills remove <skill> -y
